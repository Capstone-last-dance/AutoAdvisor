# C-07 사전등록 G2 공식 재생 (2026-11-23)

A의 v7 walk-forward 신호(`20261117_A_wfnews`), C의 사전 홀드아웃 라벨,
B가 `20261118_B_buffer_wf/metrics.json`에 인계한 A02 입력을 썼다.
신호와 시세·status·universe 등의 SHA-256을 B 인계값에 대조한 뒤
`src.backtest.g2_report`로 2016~2025년 520개 신호일을 재생했다.
2026년 홀드아웃은 사용하지 않았다. 실행 코드 커밋은
`git_commit.txt`, 입력 지문은 `metrics.json`에 있다.

| 비교 | 게이트 없음 | 사전등록 게이트 |
|---|---:|---:|
| 최대낙폭(MDD) | 68.54% | 58.97% |
| CAGR | −7.74% | −3.95% |

MDD 상대 감소율은 **13.96%**로 기준 20%에 못 미친다. 차단 종목과
비차단 종목의 20거래일 초과수익 차이 `d_t`의 HAC t값은 **−1.639**로
기준 −3 이하에 못 미친다. CAGR 비열화 조건만 충족했으므로 **G2 미달**이다.
520코호트 15,600행을 운용했고 `d_t`는 516개 신호일에서 계산됐다.
4개 신호일은 한쪽 유효 집단이 없어 미산출, 라벨·플래그 결측 쌍은 140개다.

사전등록된 스트레스 구간을 별도 진단했다(`stress_windows.csv`). 구간
첫 거래일의 전 거래일 NAV부터 마지막 거래일 NAV까지 수익률과 구간 MDD를
계산했다. 코스피200은 참고선이며 G2 판정 비교 대상은 게이트 미적용이다.
