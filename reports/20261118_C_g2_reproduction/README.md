# C G2 탐색 재현 (2026-11-18)

동봉 ZIP의 `replay_g2.py`를 `A02_processed_20261108` 시세 처리본과 함께 실행했다. 요구한 시세 5개 파일의 SHA-256이 모두 일치했다. 출력은 `comparison.csv`, `daily_nav.csv`이며 기대 파일과 2,447일 NAV·요약 지표를 `atol=1e-12`로 대조했다. 상세 지문·차이는 `metrics.json`에 있다.

이것은 **사전등록 G2 공식 판정이 아닌 탐색안 재현**이다. 스크립트는 C 프록시 소스를 메모리에서 바꾸며, ZIP에는 고정된 `crash_flag`만 있고 60일 변동성·지수 대비 하락 변동성의 생성 절차는 없다. 따라서 플래그 생성과 탐색 선택 편향은 독립 검증되지 않았다.

원래 무필터 대비 차단+현금 유지의 MDD 감소율은 26.32%, CAGR은 −7.74%에서 −1.77%, HAC t값은 −3.871로 세 수치 기준을 충족한다. 그러나 현금 보유량을 맞춘 무필터 대비 MDD 감소율은 19.21%로 20% 기준에 못 미친다. 선택한 조합의 동일 기간 탐색 성과를 공식 성공 판정으로 승격하지 않는다. G1은 이 패키지로 검증할 수 없다.
