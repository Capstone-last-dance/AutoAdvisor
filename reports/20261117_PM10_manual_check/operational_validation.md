# PM-10 실자료 재생 결과

2026-11-17 KST · 최근 실자료 범위 2026-11-09~11-16 · 격리 사본 기준 `bd686ca`

## 결함 수정과 재검증

- 완료된 검토의 일간·백필은 기존 경보 행과 `generated_at`을 보존한다. 후발 원문이 앞선 같은 사건으로 연결되면 이미 기록된 경보를 유지하고, 별개 사건만 실제 새 생성 시각으로 추가한다. 과거 날짜 단독 재실행과 전체 구간 재실행에서 쿨다운·청산을 확인했다.
- 원문·시점별 종목 매핑·KIND 확인이 끝난 날짜를 `ReviewBook.completed_days`로 전달한다. 요청 구간에 미완료일, 검토 기록과 짝이 맞는 원천 공시 누락, 미판정 후보가 있으면 저장 전에 `AlertsNotCollected`를 반환한다. 일부만 확인한 보관 자료는 `preview_reviewed_alerts`로 재생한다. 이전 8일의 부분 검증 파일은 `original_partial_replay_alerts/`에 별도로 보관했다.
- T6의 발행 수량 공란, 발행가는 있으나 수량이 없는 주식 종류는 미판정으로 남긴다. 수정 전 9% 제외가 나왔던 자료로 확인했다.

수정 후 실제 11/9~11/16 자료도 저장 없는 날짜별·구간 재생에서 같은 경보와 일정이 나왔다. 관련 테스트 182개와 하위 검사 62개가 통과했고 1개는 건너뛰었다. 패치 적용 검사 통과, 추가 API 호출 0회. ## 후속 검토

동일한 입력의 일간·백필 일치는 확인했다. 다른 시점에 근거가 추가되거나 검토 입력이 빠지는 경우에는 결함을 재현했다. 이 결과는 격리 후보에 해당한다.

1. **P1 · 과거 경보 삭제.** 후발 근거가 먼저 발행된 공시를 같은 사건의 최초 경보로 바꾸면, 백필이 이미 체결에 반영된 기존 경보를 지운다. 더 이른 접수번호의 `generated_at`은 뒤늦은 실행 시각이므로 과거 재생에서 새 경보는 빠지고 기존 쿨다운·청산도 사라진다. 운영 전 고정된 기록 또는 당시 경보 이력을 보존해야 한다.
2. **P1 · 검토 누락을 0건으로 저장.** DART 목록 창만 완료된 상태에서 빈 `ReviewBook`을 전달하면 검토 완료로 확인할 근거가 없어도 일간은 0건을 돌려주고 백필은 기존 스텁 경보를 0행 파일로 덮어쓴다. 원문·매핑·KIND 범위의 확인 상태를 결과에 연결하고, 완료를 확인한 0건과 판정 미완료를 구분해야 한다.
3. **P2 · T6 일부 수량 결측.** 두 종류 주식 중 한쪽 수량이 공란이고 주당가가 기재돼 있어도 계산에서 그 종류를 빼고 나머지 금액만으로 경보 여부를 결정한다. 보통주만 계산한 9%를 제외한 반례를 재현했다. 발행종류별 수량·가격의 근거가 불완전하면 미판정으로 처리해야 한다.

수정 전 후보 테스트 12개 통과와 위 세 반례를 함께 확인했다.
