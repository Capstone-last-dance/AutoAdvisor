## 규칙 수정 제안

1. **T1.** 거래소 원문에서 변경 전후 분류, 신규 지정 사유, 효력일을 함께 채택하고 상장 구간을 검증한다. `기타시장안내` 본문에는 기존 지정·추가 가능성·상장폐지가 함께 나올 수 있으므로 본문의 상태 전환을 확인한다.
2. **T2.** 내부결산 공통 서식에서 본문이 상장폐지 또는 실질심사 사유로 지목한 항목을 확인한다. 관리종목 지정 가능성만 있는 행은 T2에서 제외하고, 감사 전 구체적 사유를 밝힌 자율공시의 범위를 문서에 명시한다.
3. **T3.** `사실확인` 후보에서 판결 주문의 해당 혐의별 결론을 읽고, 무죄·취하·기각 등의 맥락을 확인한다. `기각`에는 유죄가 유지되는 상고 기각도 있다. 선행 사건에 연결되는 판결은 기존 경보에 붙인다. 조회 답변에서는 원 질의와 별건을 각각 확인하고, 배임수재·직원 개인비리의 경보 범위를 명시한다.
4. **T4.** 이사회 신청 결정, 법원 접수, 개시 결정의 시점을 구분한다. 본문에 계획과 접수 표현이 함께 있으면 관할법원·사건번호·당일 거래소 공시로 확인한다.
5. **T5.** 원문에 나타난 1차 부도·최종부도·법적 지급제한을 기록한다. 동일 명령 아래 다른 어음의 부도가 후속 공시될 때 새 사건으로 볼 기준을 정한다. 현재 유형 매칭은 실제 부도 확인을 기준으로 했다.
6. **T6.** `주주배정 후 실권주 일반공모`와 `주주우선공모`를 구분해 허용 방식을 정규화한다. 발행인 종목으로 전일 MC를 확인하고, 발행가액 칸에 총액이 들어간 것으로 의심되면 근거를 확인한다. JTC의 종속회사 공시에서 발행가액 칸 160억원은 운영자금 총액과 같았다. [JTC 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20180704900558)

| 동일 사건 연결 | 제목에서 횡령·배임이 빠진 조회 답변은 후보에서 누락됐다. 같은 종목·유형의 두 공시는 쿨다운 안에서 `alert → same_event`, 만료 뒤에는 `alert → alert`였다. 일간 실행이 읽는 앞선 경보는 쿨다운 범위로 제한된다. | 같은 회사·상장 구간에서 공시의 명시적 참조·사건번호·원문으로 연결한다. 매일유업의 제목에 혐의어가 없는 답변을 원 조회에 붙이고, 부인 답변의 경보 0건을 확인한다. 쿨다운을 넘긴 같은 사건은 후속으로, 기간 안에 확인된 별개 사건은 신규로 검증한다. T1의 DART·KIND 중복 공시를 한 사건으로 연결한다. |
| 공시 당시 종목 식별 | `attach_stock_codes`는 공시별 최신 목록 관측을 채택한다. 같은 접수번호의 코드가 `000001`에서 `000002`로 바뀐 합성 입력에서 과거 행이 `000002`에 `linked`로 붙었다. `link_tickers`의 충돌 검사는 입력에 든 회사와 코드의 조합을 사용한다. | 회사코드와 종목코드를 유효한 상장 구간으로 검증한다. 당시 상호와 최신 상호가 달라도 같은 구간이면 연결한다. 재사용 코드가 구·신 법인에 연속으로 붙는 사례, 목록 관측 간 코드 충돌, T6 종속회사 발행을 넣어 후대 상장 구간과 모회사 MC가 붙지 않는지 확인한다. 자료 수집일은 공개 시점·상장 증거 유효일과 구분한다. |

동일한 확인 근거로 일간 실행과 백필의 경보 접수번호·유형·쿨다운이 일치하는지 비교한다. 앞선 기록의 컷오프가 닫힌 뒤 근거가 추가되는 경우는 DEC-32의 `generated_at` 재생 규칙으로 별도 검증한다.

후속 격리 구현과 운영 자료 재생 결과는 [구현 후보](implementation.md)와 [실자료 재생 결과](operational_validation.md)에 기록했다.

## 원본과 재현

- OpenDART 문서 API **69회 시도**. 접속 실패 2회, API HTTP 응답 67회(문서 ZIP 65회, `014` 2회). 과거 ZIP 8개의 내부 경로에 `/`가 붙어 있어 정확한 접수번호를 확인한 뒤 저장된 ZIP에서 추출했다. ZIP 중 같은 접수번호 재요청은 6회다. 검토한 원문은 고유 접수번호 59건(표본 55 + 연결 근거 4). KIND 공개 공시 사본 3개를 별도로 보관했다. [OpenDART 문서 API 안내](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)
- `data/interim/pm10-manual-check-20261117/`에 ZIP·XML·텍스트, KIND 사본, `document_calls.jsonl`, `listing_and_timing.csv`, `t6_calculations.csv`가 있다. `listing_and_timing.csv`에는 공시 원보관 파일과 회사코드, 상장 기간, 날짜별 근거를 기록했다. `t6_calculations.csv`에는 직전 거래일과 원 단위 금액을 기록했다.
