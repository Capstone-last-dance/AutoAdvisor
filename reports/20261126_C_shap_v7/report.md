# C-06: A v7 폴드 모델 SHAP 분석 (2026-11-26)

## 입력과 재현

- A가 인계한 `features_v7.parquet`는 348,678행 × 38열이며 SHA-256은 `45f86be38f8a0412837fe46bd97fc81544ddb74ee33428f93554236b22ecba8f`이다. A의 `20261117_A_wfnews` 실행에 대응하는 2016~2025년 게이트·순위 모델 20개를 사용했다. 모델별 SHA-256은 `metrics.json`에 있다.
- 각 테스트 연도에서 `(date, ticker)` 정렬 후 시드 42로 5,000행을 비복원 추출했다. 두 모델 각각 50,000행을 해석했다. 2026년 자료는 표본에 포함하지 않았다.
- `python -m src.analysis.shap_report --features <features_v7.parquet> --models <20261117_A_wfnews/models> --output reports/20261126_C_shap_v7`로 생성했다. 원천 피처와 모델 가중치는 팀 드라이브에 두고 결과 표·그림 및 입력 지문을 저장소에 기록한다.

## 결과

- `top10_by_year.csv`: 모델 2종 × 테스트 연도 10개의 상위 10개 피처, 200행. `feature_importance_all.csv`: 모든 피처의 연도별 평균 절대 SHAP 값.
- 게이트에서는 `vol_60`이 10개 연도 모두 중요도 1위였다. `vol_20`, `mkt_vol_20`, `mom_12_1`, `log_mcap`도 10개 연도 모두 상위 10개에 들었다.
- 순위 모델에서는 `vol_60`이 9개 연도에서 1위였고, `high52_prox`가 2017년에 1위였다. `high52_prox`, `mkt_vol_20`, `mom_12_1`, `vol_60`은 모든 연도에서 상위 10개에 들었다.
- `rank_stability.csv`: 각 모델의 연도 쌍 45개, 합계 90개 스피어만 상관. 중앙값은 게이트 0.872, 순위 0.911이다. `figures/`에는 모델별 전체 기간 중요도 상위 3개 피처의 의존성 그림 6개가 있다.

## 해석 범위

SHAP는 해당 모델의 예측값에 대한 피처 기여를 설명한다. 게이트 값은 LightGBM 기본 이진 분류 출력의 raw score 척도, 순위 값은 모델 점수 척도이며 수익률이나 인과 효과가 아니다. 모델별 출력 척도가 달라 두 모델의 절대 SHAP 크기를 직접 비교하지 않는다. 표본은 각 연도의 전체 종목·날짜 중 5,000행이므로 개별 종목의 투자 근거로 일반화하지 않는다. 모델 성능과 G1·G3 판정은 별도의 동일 표본 평가 결과를 따른다.
