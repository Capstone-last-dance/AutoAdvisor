# 사전등록 이후 변경 기록

2026-11-09 사전등록 커밋(`docs/preregistration.md`) 이후 `configs/prereg.yaml`의 값이나 사전등록한 설계를 바꿀 때 적는다. 사람이 승인한 변경만 반영한다 (R-02). 다음 경우도 여기에 적는다.

- 부록 1 `allowed_deviations`의 사전 허용 변경을 적용할 때 (8장)
- 커밋한 forward test 신호의 오류를 새 커밋으로 고칠 때 (6.8절)
- 미래 정보 누수를 고치고 다시 실행할 때 (11장)
- 벤치마크를 코스피 200 TR로 바꿀 때 (4.5절)

원래 설정으로 낸 결과도 지우지 않고 함께 보고한다 (R-11, 8장).
