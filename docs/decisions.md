후속으로 상세 API를 **총 2회·재시도 없이** 실측했다. 삼성SDI의 최초일 하루(20250314~20250314) 조회는 후속 `20250519000120`과 변경된 목적금액을, 고려아연의 최초일 하루(20241030~20241030) 조회는 후속 `20241114000001`과 금액/수량 '-'를 반환했다(각 HTTP 200/000·1행). 최초일 조회가 과거 스냅샷을 보장하지 않는 반례이므로 과거 T6 입력에 직접 소급하지 않는다. 원래 전체 수집·키·코드·설정은 보존하고 이번 조회 원본/호출 수는 별도 보관했다. 현재 관측이며 모든 회사/기간의 반환 방식을 일반화한 것은 아니다.

[공식 원문파일 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)는 `document.xml`에 14자리 rcept_no를 명시해 ZIP 원본을 받도록 한다. 후속으로 최초 접수번호 20250314000027·20241030000098의 ZIP을 각 1회 조회해 HTTP 200·XML 텍스트의 최초 수량/가격/목적금액 일치를 확인했다. 이번 조사 호출은 상세 2회+원문 2회, 합계 4회이며 원본을 보관했다. 일반 추출기·전체 서식/버전 관계·정확한 과거 가용 시각은 미검증이다. DART와 KRX의 접수번호도 같다고 가정하지 않는다.

```text
[결정 필요]
상황: 6.10절은 상세 API에서 발행금액을 읽도록 하나 총액/발행가액 필드가 없고, 실제 두 초기일 조회에서 후속 정정 접수번호와 값이 반환됐다. 최초 예정가와 후속 실제가, 철회 문서를 구분해야 한다.
관련 조항: 6.10절, Q-07, R-03, R-08, R-09, DEC-09
선택지: A) 목적별 금액 합계를 총액 대용으로 사용 B) 접수번호별 원문파일에서 같은 시점 신주 수·발행가액으로 검증하고 예정/확정·정정 버전을 구분 C) 검증 불가 사유를 보존하고 미판정 유지
추천: B를 PM 검토안으로 선정하고 검증 불가 시 C를 적용. A는 두 표본의 일치만으로 일반화하지 않음.
영향: T6 금액 의미·원문 보완 경로·문서 시점 검증. 기존 10%/MC(d−1)·YAML·공용 출력 스키마는 이번 조사에서 변경하지 않음.
```

사용자의 PM 기술 판단 위임 범위에서 검토안을 구체화한 기록이다. 두 API 반례를 확인했으나 원문 보완 계약·전체 정정 관계를 확정한 것은 아니며, 의존 실행을 차단한 채 C 검토·D 공용 접점과 연결한다. 현재는 로컬 미커밋 문서이며 검토 요청을 새로 전송하지 않았다.

## 2026-11-02 Q-09 원저자 경로·대체 기반 모델 확인

[연구실](https://sites.google.com/snu.ac.kr/gsds-nlp/research)이 연결한 [SC 저장소](https://github.com/snunlp/KR-FinBert-SC)·기반 저장소를 추가 확인했다. SC에는 README만 있으며 가중치 이용 조건·학습 자료 기간·분류 평가 분할을 확인하지 못했다. 기반 run_mlm.py의 Hugging Face 예제 코드에는 Apache 2.0 헤더가 있으나 이를 SC 가중치의 이용 조건으로 확대하지 않는다. 문서 커밋일도 모델의 과거 공개 시각/학습 종료일을 대신하지 않는다.

[kakaobank/kf-deberta-base](https://huggingface.co/kakaobank/kf-deberta-base)는 코드/모델의 MIT 조건을 확인한 대체 **기반 후보**다. 공개 아키텍처는 MaskedLM이므로 바로 쓸 감성 분류기가 아니며 별도 분류 학습·허용 시점 자료/폴드 검증이 필요하다. Q-09 최종 모델·FILL_는 유지하고 설치·학습·추론은 하지 않았다. 원저자 문의 초안은 로컬에만 보관하며 외부 메시지는 전송하지 않았다.
