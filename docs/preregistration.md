## T1 출처와 경보 식별자 검토

KIND 신규 지정 공시 7건은 기존 OpenDART 보관본에서 같은 지정 공시를 확인하지 못했다. DART의 소속부변경 원문 2건에서는 실제 신규 지정과 효력일을 확인했다. `events.triggers.T1`에는 두 출처를 사용하고 실제 신규 지정을 확인한다는 조건을 넣었다. 원문 확인 전에 제목 단계에서 지정 우려·사유 발생·추가·변경·해소·해제·예고 안내와 내부결산시점 자율공시를 `exclude_terms`로 뺀다. 2015~2025년 OpenDART 후보 1,029건 중 원문 확인 대상은 5건(소속부변경 2건 포함)이다. KIND 정정 공시의 제목 표기는 보관 자료에 없어 KIND 수집 때 확인한다. 공시가 이용 가능해진 시점과 지정 효력일을 별도로 다룬다. [KIND 코아스 지정 공시](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20251002000776), [DART 바이오빌 소속부변경 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20190215900345)

공용 경보는 DART 14자리 접수번호와 `KIND:<acptno>`를 같은 문자열 열에 저장하는 안이다. 임소현(D)은 출처별 원문 링크와 DEC-09 시점 열 연동을, 조윤상(B)·손석범(C)은 접수번호를 문자열로 취급하고 같은 신규 지정으로 쿨다운·청산이 중복되지 않는지를 확인한다. 장지원(PM)은 KIND 수집 범위와 시점·종목 연결 근거를 마련한다. 합의 후 구현·검증하며, 이 초안은 전원 확인 및 공식 사전등록 커밋과 구분한다.

## T2~T6·이벤트 피처 신규 사건 검토

2015~2025년 OpenDART 제목 588,868건에서 현재 키워드로 후보를 찾은 뒤 신규 사건만 남기는 조건을 정했다. `events.title_filters`에 따라 제목 앞의 `[첨부추가]`·`[정정명령부과]`는 떼고 판정한다. DART 관련보고서 목록에서 이 표시가 붙은 접수번호가 원 공시 자체로 확인됐기 때문이다([코아시아](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20150414002106), [이렘](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20181213000009)). 그다음 모든 후보에서 `[기재정정]`·`[첨부정정]`으로 시작하는 후속 정정, 자회사·종속회사 공시, 철회·취소 공시를 뺀다. 자사주 신탁계약의 `[연장결정]`은 정정이 아니라서 넣지 않았다. 정정 후보의 99.4%는 같은 회사의 원 공시가 앞서 있고, 증자·사채 정정은 절반 이상이 원 공시 28일 뒤에 나와 신규로 세면 같은 결정이 다시 잡힌다. 유형별로는 T2의 우려·기한·제외·해제 안내, T3의 진행사항·풍문 조회공시·무혐의, T4의 취하·기각·사유 해소, T5의 풍문 해소 안내를 뺀다(`require_any`, `exclude_terms`).

T2의 `기타시장안내(상장적격성 실질심사관련)` 계열은 거래소가 심사 대상 여부를 정하려고 매매거래를 정지한 안내였다. 원문 5건에서 확인했으며 심사 절차의 첫 공개 신호이므로 신규에 넣었다. [엔티피아](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20150324900052), [신일산업](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20151105800004)

| 확인 담당 | 확인할 내용 |

| 조윤상(B)·손석범(C) | 같은 종목·같은 유형의 신규 공시가 쿨다운 안에 다시 나올 때 새 경보로 세지 않고 기존 사건에 연결하는 안, 이때 쿨다운을 늘릴지 여부 |
