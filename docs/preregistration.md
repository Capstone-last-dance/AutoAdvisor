## T1 출처와 경보 식별자 검토

KIND 신규 지정 공시 7건은 기존 OpenDART 보관본에서 같은 지정 공시를 확인하지 못했다. DART의 소속부변경 원문 2건에서는 실제 신규 지정과 효력일을 확인했다. `events.triggers.T1`에는 두 출처를 사용하고 실제 신규 지정을 확인한다는 조건을 넣었다. 원문 확인 전에 제목 단계에서 지정 우려·사유 발생·추가·변경·해소·해제·예고 안내와 내부결산시점 자율공시를 `exclude_terms`로 뺀다. 2015~2025년 OpenDART 후보 1,029건 중 원문 확인 대상은 5건(소속부변경 2건 포함)이다. KIND 정정 공시의 제목 표기는 보관 자료에 없어 KIND 수집 때 확인한다. 공시가 이용 가능해진 시점과 지정 효력일을 별도로 다룬다. [KIND 코아스 지정 공시](https://kind.krx.co.kr/common/disclsviewer.do?method=search&acptno=20251002000776), [DART 바이오빌 소속부변경 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20190215900345)

공용 경보는 DART 14자리 접수번호와 `KIND:<acptno>`를 같은 문자열 열에 저장하는 안이다. 임소현(D)은 출처별 원문 링크와 DEC-09 시점 열 연동을, 조윤상(B)·손석범(C)은 접수번호를 문자열로 취급하고 같은 신규 지정으로 쿨다운·청산이 중복되지 않는지를 확인한다. 장지원(PM)은 KIND 수집 범위와 시점·종목 연결 근거를 마련한다. 합의 후 구현·검증하며, 이 초안은 전원 확인 및 공식 사전등록 커밋과 구분한다.

## T2~T6·이벤트 피처 신규 사건 검토

2015~2025년 OpenDART 제목 588,868건에서 현재 키워드로 후보를 찾았다. `events.title_filters`에 따라 제목 앞의 `[첨부추가]`·`[정정명령부과]`를 떼되 원 접수번호와 `available_at`을 유지한다. 모든 후보에서 `[기재정정]`·`[첨부정정]` 후속 정정과 철회·취소를 신규 후보에서 제외한다. `[연장결정]`은 나머지 조건으로 판정한다. [코아시아 원 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20150414002106), [이렘 원 공시](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20181213000009)

11/4 손석범(C)의 변경 요청을 반영해 자회사·종속회사 제외를 모회사 T4·T5 자동 경보에 한정했다. 해당 원 공시는 보존하고 다른 경보와 `ev_*`는 각 유형의 조건으로 판정한다. T3은 풍문·조회공시·답변이 제목에 있으면 회사의 답변 원문으로 확인한다. 조회 요청·미확정·부인 답변은 경보 없이 보존한다. 회사가 횡령·배임 혐의 발생이나 관련 피소·고소 사실을 확인하면 그 확인 공시의 `available_at`부터 적용한다. [PR #16](https://github.com/Capstone-last-dance/AutoAdvisor/pull/16)

11/4 손석범(C)·조윤상(B)은 동일 사건의 후속 공시에는 쿨다운을 연장하지 않고, 별개의 신규 사건에는 새 20거래일을 적용하는 데 의견을 모았다. 사건을 연결할 때는 그 시점에 공개된 원 공시 참조나 사건·절차 식별자, 원문 근거를 쓴다. 같은 종목·유형 안에서 구분이 불명확하면 추가 근거가 공개될 때까지 보류한다. 새 경보가 겹치면 각 경보의 20거래일 중 하나라도 유효한 동안 신규 매수를 막는다.

PM-10에서 다음 반례를 구현 검증에 사용한다. 조회공시 답변의 확인 사례와 거래일 검증은 별도로 수행한다.

| 입력 | 기대 결과 |
|---|---|
| 모회사의 자회사 회생 신청·종속회사 부도 공시, 모회사의 종속회사 배당 공시 | T4·T5 자동 경보 없이 공시 보존. 배당은 `ev_dividend`의 기존 조건으로 판정 |
| 제목에 ‘횡령 혐의발생’을 포함한 거래소 조회 요청 또는 회사 미확정·부인 답변 | T3 경보 없음 |
| 회사가 횡령 관련 피소를 확인한 답변. 제목에는 ‘풍문’과 ‘답변’만 표기 | 확인 공시의 `available_at`부터 T3 경보 1건. 앞선 풍문 날짜에는 경보 없음 |
| 쿨다운 중 같은 사건의 정정 또는 같은 접수번호의 `[첨부추가]` 표시 | 원 경보에 연결하고 기존 만료일 유지 |
| 쿨다운 중 같은 종목·유형에 별개의 신규 사건 확인 | 새 경보와 다음 KRX 거래일부터 20거래일 적용 |
