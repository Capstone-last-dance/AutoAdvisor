# B-09 탐색 실험 기록 (브랜치 `b09-explore`)

이 문서는 브랜치 `b09-explore`에만 있다. 방향과 절차는 main의 `docs/design_B.md` 3.7절을 따른다. 결과는 모두 '탐색'이고 KPI 판정에 쓰지 않는다 (R-15, G7은 R-02도).

## 1. 브랜치 운영
- main에서 갈라졌다 (`fd3e983`, 11/18). main에 병합하지 않고, 필요한 결과만 main 문서로 옮긴다.
- 이 브랜치에서는 코드를 제한 없이 고친다 (B 코드, `configs/prereg.yaml`, 다른 역할 코드 포함). 다만 공용 코드(`src/`)를 고치면 대조 실행(바꾼 것 없음)이 공식 결과를 재현하는지 다시 확인한다.
- 최종 모델은 2021~2025 확인을 거친 변형 중 성능이 가장 좋은 것으로 고른다. 2021~2025를 본 뒤 다시 고친 변형은 '확인 없음'으로 표시한다. forward test나 발표의 운용 모델로 쓰려면 PM 결정(DEC)이 먼저 있어야 한다.
- 11/18 실행분은 스크래치에서 시작했고 같은 날 이 브랜치로 옮겼다. 코드와 원장은 같은 내용이다. 그 뒤로는 이 폴더에서 돌린다.
- 실행은 사용자가 한다 (11/18 사용자 결정). B는 실행 명령을 주고, 끝났다는 연락을 받으면 결과를 읽어 다음 실험을 정한다. 11/18 스크래치에서 B가 돌리던 RL 학습 선별은 끝난 작업 5개(R0 2016·2017·2019, R-smoothk-0.5 2016·2017)를 `explore/b09/runs/`로 옮기고 멈췄다. 나머지는 사용자가 같은 작업 파일로 이어서 돌린다 (끝난 작업은 건너뛴다).

## 2. 실험 도구 (`explore/b09/`)
실행: `.venv/Scripts/python.exe -I explore/b09/run.py <스크립트> [인자]` (`-I`는 스크립트 폴더를 경로에 넣지 않아 `run.py`가 넣는다)

| 파일 | 내용 |
|---|---|
| `common.py` | 입력 읽기(`Ctx`, 9.3절 표·v7 시험 신호·M9 경보), C 엔진, 버퍼 실행 고리(`buffer_run`: 노출·차단·리밸런싱 주기·종목 선택 변형), 지표(`buffer_wf_report.replay/summary`), 원장 |
| `control.py` | 대조 실행: 버퍼 10년·2016~2020이 공식 `20261118_B_buffer_wf`와 같은지 |
| `buffer_batch.py b1` / `b2` | G7 트랙(M8 변형)과 구성 트랙(신호·버퍼 변형) 선별 |
| `confirm_g7.py` | G7 확인 대상 2개의 2021~2025·10년 확인 |
| `rl_screen.py` | RL 변형 환경 `XEnv`(행동 해석·보상 변형)와 폴드 학습·선별 운용. `train <id> <폴드> <시드>`, `worker <작업 파일> <슬롯> <슬롯 수>`, `eval <id> <시드>` |
| `rl_check.py` | RL 대조: 공식 체크포인트 운용이 공식 positions와 같은지, R0 학습이 공식 지문과 같은지 |
| `rl_infer.py [--perseed] [id ...]` | 공식 정책을 재학습 없이 운용 때 해석만 바꾼 변형(I-*). `--perseed`는 같은 변형의 시드별 값 → `infer_perseed.csv` |

| `confirm_combo.py` | G7 확인 M8 변형 2개 × G5 확인 RL 변형 2개를 한 시스템으로 합친 확인 (사후 조합). 대조: 버퍼 + M8 변형이 `confirm_g7.json`과 같은지 |
| `rl_eval_batch.py [시드] [id ...]` | 학습 변형 중 폴드 2016~2020이 다 끝난 것을 선별 구간에서 평가 → `rl_search_s{시드}.csv`(같은 id 행만 새 값으로), 원장. R0은 공식 positions와 같은지도 본다 |
| `jobs_all.txt`, `jobs_b2.txt` | RL 학습 선별 작업 84개 (시드 0), 2차 20개 (시드 1 + R-tpen-0.01) |
| `prelim_diag.py` | 11/18 예비 진단 (design_B 3.7 '출발점') |
| `ledger.jsonl` | 원장 (계획 행·결과 행, 지우지 않는다) |
| `*_search.csv`, `confirm_g7.json`, `rl_check.out.json` | 결과 표 |
| `runs/` (git 제외) | RL 선별 체크포인트·positions |

- 메모리: 표를 읽은 프로세스 하나가 약 2 GB라, 이 PC(15 GB)에서는 동시에 2개까지 돌린다.
