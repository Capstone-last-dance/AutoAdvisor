# C-02·C-03 선행 구현 현황 (2026-11-03)

## 구현 및 검증

- `src/common/guards.py`: 학습 신호일 상한, 홀드아웃 라벨 개봉일과 명시 플래그, `purge_signal_dates(signal_dates, *, trading_days, h, next_segment_first_signal)`. 사전등록 날짜와 KRX 거래일은 호출자가 전달한다.
- `src/backtest/labels.py`: A가 제공할 가격·지수·유니버스·거래정지·상장폐지 표를 받아 4.6절 라벨을 메모리에서 계산한다. 거래정지로 인한 종료 연기와 결측 건수, 명목·실제 종료일 진단값도 반환한다.
- `src/backtest/accounting.py`: 체결 제한, 매수·매도 비용, 주문 체결, 현금 및 일별 NAV의 공통 함수. 목표 비중을 주문 수량으로 바꾸는 방식은 아직 확정하지 않았다.
- `src/backtest/engine.py`: B의 `ExecutionEngine` 인터페이스에 맞춘 `initial_state`·`run_period` 구현. 다음 거래일 종가 체결, 일별 NAV, 벤치마크 구간 수익, 다음 신호일 관측 비중, M9 청산·재시도, 쿨다운, 거래정지·가격 제한, 상장폐지 평가를 한 함수로 처리한다. 현금 부족 시 매도 후 모든 가능한 매수를 같은 비율로 줄이는 **B 제안안**을 적용했으며 PM 결정 전에는 잠정 구현이다. 합성 6거래일 구간 5,000회 측정에서 평균 0.38 ms/호출(단일 종목, 현 로컬 환경)이다. 종목 수·이벤트 수가 다른 실제 데이터 성능은 별도 측정이 필요하다.
- `src/backtest/labels.py`: `publish_labels`가 홀드아웃 가드를 재검사한 뒤 D 공용 `io.write_table("labels")`로 저장한다. 실제 원천 자료로 라벨 파일을 만든 것은 아니다.
- `src/backtest/validation.py`: G0 목표 비중을 B의 `sectors_at`·`check_invariants`로 검사한다. M8 미적용 G7 실행은 호출자가 `m8_mode="off"`를 명시해야 한다.
- `src/backtest/metrics.py`: 6.6절의 CAGR, 연 초과수익, 주간 초과수익, IR, MDD, 회전율, rank IC/HAC, ROC-AUC, lift@10%, 하방·반등 포착률. B-01 `IRFunction` 연결용 `validation_ir`는 미산출 IR을 NaN으로 전달한다.
- `tests/`: 손계산 예제, 홀드아웃 경계, 거래정지·상장폐지, 미체결, 비용 0 동일가중 리밸런싱, 공용 I/O 라벨 왕복, 구간 NAV·이벤트 우선순위·G0 검증. 테스트는 합성 자료만 사용한다. C 관련·D 공용 I/O 테스트 62개와 하위 테스트 51개가 통과했다.

## 실제 산출물 연결에 필요한 입력

1. A의 `prices`, `index`, `universe`, `status`, `delisted` 파일과 KRX 거래일 목록. 지금 저장소에는 실제 자료가 없다.
2. `configs/prereg.yaml`의 공식 확정값. 현재 개발 초안의 날짜·기간·비용을 실험 결과 확정값으로 간주하지 않는다.
3. 비용 포함 목표 비중 체결의 현금 부족 규칙. B 제안인 매도 우선·매수 동일 배율 축소를 구현했으나 PM `decisions.md` 확정이 필요하다. 엔진의 `execute_orders`는 여전히 수량 기준 순수 함수이며 현금 초과를 오류로 처리한다.
4. 거래 재개 지연 라벨의 실제 종료일까지 추가 purge하는 규칙. C는 신호일 전체 제외 코드를 준비했으나 DEC-09와 A·B의 동일 표본 합의가 필요하다.
5. A의 실제 가격·거래정지·상장폐지 표에서 평가 가격 공백을 처리하는 규칙. 현재 엔진은 거래정지일에도 평가 가능한 수정종가를 요구하며 상장폐지일은 명시적 최종 가격을 받는다.
6. B의 RL 환경과 버퍼 백테스트에 실제 엔진을 연결하는 B-05 작업. C 인터페이스 구현과 합성 검증은 끝났으나 B 연결·동일 입력 결과 검증은 아직이다.
7. M9 경보의 실제 `available_at`·청산·쿨다운 출력, 업종 원천, `investor_flows` 원천 및 사전등록 계약. 현재 엔진은 적용 거래일별 이벤트 집합을 주입받는다.

위 입력과 결정을 받으면 2025년 신호일까지 라벨 파일을 만들고, 실제 walk-forward NAV와 6.6절 완료 기준의 전체 기간 검증을 진행한다. 2026년 홀드아웃 신호일 라벨은 개봉 조건을 충족할 때까지 생성하지 않는다.
